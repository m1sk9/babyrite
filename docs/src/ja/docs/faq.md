# よくある質問

うまく動かない場合は [トラブルシューティング](./troubleshooting) を参照してください．

## 導入・運用

### Q. 自分でホストする必要がありますか?

はい．

babyrite はセルフホスト型の Bot です．公開ビルドはありません．

[Discord Bot の準備](./discord-bot) と [はじめる](./getting-started) の手順に従って，自分の環境で起動してください．

### Q. 1 つの babyrite を複数のサーバーで使えますか?

使えます．1 つのプロセスで，Bot が参加しているすべてのサーバーを処理します．

ただし babyrite はシャードを 1 つしか使わないため，Discord がシャーディングを必須とする規模 (2,500 サーバー) を超えて運用することはできません．

### Q. スラッシュコマンドはありますか?

ありません．babyrite はメッセージ内のリンクを検出して自動で展開するだけで，操作するためのコマンドは提供していません．

### Q. メッセージやファイルの内容を保存しますか?

保存しません．babyrite はデータベースを持たず，引用したメッセージや GitHub のファイルの内容はどこにも保存しません．

メモリ上にキャッシュするのは，権限の判定に使うチャンネル情報とロール権限だけです．キャッシュは最大 1 時間で失効し，プロセスを終了すると消えます．詳しくは [キャッシュシステム](./features/cache) を参照してください．

::: info ログに含まれる情報

ログには，リンクを含むメッセージのメッセージ ID・サーバー ID・チャンネル ID・送信者の名前が出力されます．メッセージの本文は出力されません．

:::

## メッセージ引用

### Q. 特定のリンクだけ引用させないことはできますか?

リンクを `<>` で囲むと，そのリンクは展開されません．

```md
<https://discord.com/channels/1390203929182339092/1496887099536838706/1497066171390886000>
```

### Q. メッセージ引用を無効にできますか?

設定で無効にすることはできません．

メッセージ引用は babyrite の中心となる機能のため，feature flag を用意していません．

特定のチャンネルで引用させたくない場合は，そのチャンネルで babyrite のロールから「チャンネルを見る」などの権限を外してください．

### Q. 別のサーバーのメッセージを引用できないのはなぜですか?

Discord の権限はサーバーごとに定義されるため，babyrite は別のサーバーのメッセージを引用元のメンバーが読めるかどうかを判定できません．閲覧権限のない人にメッセージが漏れるのを防ぐため，別のサーバーのメッセージリンクは展開しません．

### Q. 引用先のメッセージを編集・削除したら，展開結果も変わりますか?

変わりません．

展開結果は引用した時点の内容で投稿され，その後の編集や削除は反映されません．展開結果を消したい場合は，メッセージの管理権限を持つメンバーが削除してください．

## GitHub パーマリンク展開

### Q. GitHub パーマリンク展開だけを無効にできますか?

できます．`config.toml` で次のように設定してください．

```toml
[features]
github_permalink = false
```

### Q. GitLab や Gist のリンクにも対応していますか?

対応していません．`https://github.com/{owner}/{repo}/blob/...` の形式のリンクのみ展開します．

### Q. プライベートリポジトリのファイルを展開できますか?

できません．

babyrite は認証なしで `raw.githubusercontent.com` からファイルを取得するため，公開リポジトリのファイルのみ展開できます．

### Q. 表示される行数を増やせますか?

`config.toml` の `github.max_lines` で変更できます．デフォルトは 50 行です．

```toml
[github]
max_lines = 100
```

なお，Discord のメッセージには文字数の上限があるため，行数を増やしすぎると投稿に失敗することがあります．
