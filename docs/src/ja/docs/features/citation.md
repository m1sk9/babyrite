# メッセージ引用 <Badge type="tip" text="v0.1.0~" />

メッセージリンクを送信すると，そのメッセージ内容を埋め込みコンテンツとして展開します．

```md
https://discord.com/channels/1390203929182339092/1496887099536838706/1497066171390886000
```

メッセージリンクをコピーするには次の手順をクライアント上で踏みます．

::: tabs
== デスクトップ版・ブラウザ版

1. メッセージを右クリックする
2. コンテキストメニューから **メッセージリンクをコピー** をクリックする

![](/features/citation/citation-desktop.gif)

== モバイル版・タブレット版

1. メッセージを長押しする
2. メニューから **メッセージリンクをコピー** をタッチする

![](/features/citation/citation-mobile.gif)

:::

- 1メッセージあたり最大3件までのリンクを展開します．
- NSFW チャンネルの内容は展開されません．NSFW チャンネル配下のスレッドも同様です．
- Bot が送信したメッセージ内のリンクには反応しません．
- DM 内のリンクには反応しません．サーバー内のメッセージのみが対象です．

### 展開される内容

引用先のメッセージは，次の内容を含む埋め込みとして表示されます．

| 項目 | 内容 |
| --- | --- |
| 作成者 | 送信者の名前とアバター |
| 本文 | メッセージの本文 |
| 画像 | メッセージに添付された最初のファイル |
| フッター | 引用先のチャンネル名 |
| タイムスタンプ | メッセージの送信日時 |

複数のリンクを含む場合は，すべての埋め込みを 1 件の返信にまとめて投稿します．

### 返信とメンション

- 展開結果は元のメッセージへの返信として投稿され，リンクを送信したユーザーにのみ通知されます．
- 引用先のメッセージに `@everyone` やユーザー・ロールへのメンションが含まれていても，展開時に通知は飛びません．

### 引用をキャンセル

引用を行いたくない場合はメッセージリンクを `<>` で囲むとそのリンクは無視されます．

```md
<https://discord.com/channels/1390203929182339092/1496887099536838706/1497066171390886000>
```

## チャンネル権限に対する挙動

babyrite はチャンネルの権限に対して次のような挙動になります．

- 別のサーバー (ギルド) のメッセージリンクは展開されません．
  - 権限はサーバーごとに定義されるため，babyrite は他サーバーのチャンネルの閲覧可否を判定できません．
- プライベートスレッドおよび DM のメッセージは展開されません．
- リンク先のメッセージは，引用元チャンネルを閲覧できるメンバー全員が読める場合のみ展開されます．
  - リンク先のメッセージを読むには，そのチャンネルの「チャンネルを見る」と「メッセージ履歴を読む」の両方が必要です．
  - ボイスチャンネルおよびステージチャンネルでは「接続」も必要です．
  - 権限は複数のロールを持つメンバーも含めて Discord と同じ方法で計算します．
  - 引用元チャンネルを閲覧できるのにリンク先のメッセージを読めないメンバーが 1 人でもいれば展開されません．
- 公開スレッドは親チャンネルの権限をもとに可否を判定します．
- 個別に閲覧を許可・拒否されているメンバーは，そのメンバーの実際のロールを取得して判定します．
  - 1 つのリンクにつき取得が必要なメンバーが 10 人を超える場合は，安全のため展開されません．
- 引用先が引用元と同じチャンネルの場合は，上記の権限チェックをスキップしてそのまま展開します．

## サポートされているメッセージリンク

babyrite が現在サポートしているメッセージリンクは以下の通りです:

- `discord.com`
- `canary.discord.com`
- `ptb.discord.com`

これ以外のメッセージリンクは安全上の理由により無視されます.

::: warning 一部 Windows 版で使用されているドメインについて

一部 Windows 版で使用されている `discordapp.com` ドメインは古い形式です．対象のドメインは過去のバージョンで対応を打ち切りました．

詳しくは以下の Issue を参照してください．

[Support discordapp.com - m1sk9/babyrite #172](https://github.com/m1sk9/babyrite/issues/172)

:::

## キャッシュシステム

babyrite はメッセージリンクを引用した際，ギルドのチャンネルリスト・メッセージ送信元のチャンネルをキャッシュします.

2回目以降同じチャンネルのメッセージを引用した場合は, Discord API には問い合わせずキャッシュからチャンネルを取得します.

詳しくは [キャッシュシステム](./cache.md) を参照してください.
