# トラブルシューティング

よくある問題と確認すべき点をまとめます．

原因を調べる際は，まずデバッグログを有効にしてください．リンクを展開しなかった理由 (別のサーバーのリンク，NSFW，権限など) が出力されます．

```shell
RUST_LOG=babyrite=debug
```

設定ファイルで指定する場合は `log.level = "babyrite=debug"` です．詳しくは [設定](./configuration#ロギング) を参照してください．

## 起動直後に終了する

| 確認すること                    | 説明                                                                                                                                                                  |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DISCORD_API_TOKEN` が正しいか  | トークンが誤っている，または再発行で無効になっていると接続が拒否されます．                                                                                            |
| Message Content Intent が有効か | 無効だと接続が拒否されます．[Discord Bot の準備](./discord-bot#message-content-intent-を有効にする) を参照してください．                                              |
| 設定ファイルを読み込めるか      | `CONFIG_FILE_PATH` のファイルが存在しない，または TOML として不正な場合は `Failed to read configuration file.` / `Failed to parse configuration file.` で終了します． |

## 設定が反映されない

- 設定ファイルのパスは `CONFIG_FILE_PATH` 環境変数で指定します．指定しない場合はデフォルト設定で起動します．
- Docker で使う場合は，設定ファイルをコンテナへマウントし，コンテナ内のパスを `CONFIG_FILE_PATH` に指定してください．
- 設定ファイルは起動時にのみ読み込まれます．変更後は babyrite を再起動してください．

## メッセージリンクが展開されない

| 確認すること                                    | 説明                                                                                                                                                                                       |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| リンクを `<>` で囲んでいないか                  | 囲まれたリンクは無視されます．                                                                                                                                                             |
| 1 メッセージに 4 件以上のリンクを貼っていないか | 展開されるのは最初の 3 件までです．                                                                                                                                                        |
| 対応しているドメインか                          | `discord.com` / `canary.discord.com` / `ptb.discord.com` のみ対応しています．`discordapp.com` は対応していません．                                                                         |
| 同じサーバーのメッセージか                      | 別のサーバーのメッセージリンクは展開されません．                                                                                                                                           |
| NSFW チャンネルではないか                       | NSFW チャンネルとその配下のスレッドは展開されません．                                                                                                                                      |
| 引用元のメンバー全員が引用先を読めるか          | 引用元チャンネルを閲覧できるメンバー全員が，引用先チャンネルの「チャンネルを見る」と「メッセージ履歴を読む」を持っている必要があります．ボイス・ステージチャンネルでは「接続」も必要です． |
| 個別に権限を設定したメンバーが多すぎないか      | 個別に閲覧を許可・拒否されたメンバーのうち，確認が必要なメンバーが 1 つのリンクにつき 10 人を超えると展開されません．                                                                      |
| プライベートスレッドではないか                  | プライベートスレッドは展開されません．                                                                                                                                                     |
| babyrite が引用先を閲覧できるか                 | babyrite に View Channels と Read Message History (ボイス・ステージチャンネルでは Connect も) の権限がないチャンネルのメッセージは取得できません．                                         |

権限に関する挙動の詳細は [メッセージ引用](./features/citation#チャンネル権限に対する挙動) を参照してください．

::: tip チャンネルの権限を変更した直後の場合

babyrite はチャンネル・ロールの変更を Discord から受け取るとキャッシュを破棄するため，通常は即座に反映されます．再接続中に変更を取りこぼした場合でも 1 時間以内に反映されます．詳しくは [キャッシュシステム](./features/cache) を参照してください．

:::

## GitHub パーマリンクが展開されない

| 確認すること                                    | 説明                                                                                                                                      |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 機能が有効か                                    | `config.toml` で `features.github_permalink = false` にしていないか確認してください．                                                     |
| `blob` を含む URL か                            | `https://github.com/{owner}/{repo}/blob/{ref}/{path}` の形式のみ対応しています．リポジトリのトップやディレクトリの URL は展開されません． |
| 公開リポジトリか                                | babyrite は認証なしでファイルを取得するため，プライベートリポジトリのファイルは展開できません．                                           |
| ファイルが大きすぎないか                        | 表示する行までに読み込んだデータが 1MB を超えると展開されません．                                                                         |
| 1 メッセージに 4 件以上のリンクを貼っていないか | 展開されるのは最初の 3 件までです．                                                                                                       |

詳しくは [GitHub パーマリンク展開](./features/github) を参照してください．

## シンタックスハイライトが効かない

Discord のコードブロックは [highlight.js](https://highlightjs.org/) でハイライトされるため，highlight.js が対応していない言語はハイライトされません．

babyrite の拡張子の対応表は [GitHub パーマリンク展開](./features/github#サポートされている拡張子) を参照してください．対応しているはずの言語でハイライトされない場合は，[Issue を作成してください](https://github.com/m1sk9/babyrite/issues/new)．
